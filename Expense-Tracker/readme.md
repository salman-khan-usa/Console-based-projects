📘 Expense Tracker (Console-Based)
📌 Overview

This is a console-based Expense Tracker built using Python.
The application allows users to record daily expenses, view them, and analyze spending by category.
The goal of this project is to strengthen Python fundamentals, especially lists, dictionaries, loops, functions, and basic file handling.

⚙️ Features

➕ Add new expenses (date, amount, category, description)

📄 View all recorded expenses

📊 Spending analysis:

Total amount spent

Category-wise spending summary

💾 Expenses are also saved to a file for record-keeping

🚪 Exit option for clean termination
