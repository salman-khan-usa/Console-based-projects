# Instagram Follow Checker (Set Operations)

This is a simple Python program that uses set operations to compare:

People I follow

People who follow me back

Mutual followers

People who don’t follow back, etc.

It was created for practicing Git and version control, especially using the cloning method to push code to GitHub.

Features

Find people who don’t follow back

Find mutuals

Combine all unique accounts

Practice set operations in Python

Technologies

Python

Git & GitHub (cloning workflow)
